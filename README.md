# 🌌 Curated Wallpaper Collection

A personal repository of high-quality wallpapers that I've collected over time. Whether you're looking for stunning landscapes, minimalist art, or vibrant abstract designs, this collection contains my absolute favorites.

## 🖥️ Resolution

All wallpapers in this repository are perfectly suited for **2560x1440 (1440p / QHD)** displays. They offer crisp, clear visuals without any pixelation or stretching on 2K monitors.

## 🔗 Sources

The images in this collection were carefully handpicked from two of the best wallpaper and photography communities on the web:

* **[Wallhaven](https://wallhaven.cc/)** - An incredible database for high-quality digital art, anime, and general wallpapers.
* **[Unsplash](https://unsplash.com/)** - Beautiful, freely-usable photography sourced from talented creators worldwide.

## 📥 How to Use

1. Browse the repository to find a wallpaper you like.
2. Click on the image file.
3. Click the **Download raw file** button (the small download icon near the top right of the image preview) to save it in its full, uncompressed 1440p resolution.
4. Set it as your desktop background and enjoy!
